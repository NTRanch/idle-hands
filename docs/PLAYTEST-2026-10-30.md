# Playtest record — Idle Hands v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped wasm core in demo mode plays
  each level to a terminal screen. Pass = victory.
- `node tools/settings-check.mjs`: settings bridge round-trip;
  settings reachable from boot; memory bridge shifts the actor
  (fresh 0.00 vs remembered 0.27 starting loneliness).
- `node tools/perf.mjs`: step budget.
- `odin test src/tests`: 11 tests, validation + adversarial split.
- D-221 visual spot check: frames extracted from the final preview
  MP4s at viewing size and inspected — SHOULD: dark rope room, centred
  seated figure whose gaze/blink/posture read at a glance, legible
  HUD, coils and window placed clear of the figure. First pass found
  three FAILs (HUD counter collision, window hidden behind the HUD,
  look-glow ring erasing her face); all fixed, re-captured,
  re-inspected PASS.

- Level 2 — Rope Practice: VICTORY, 721 steps, 3 sequences.
- Level 3 — The Long Quiet: VICTORY, 9375 steps (150 s), 148
